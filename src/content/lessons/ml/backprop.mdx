Чтобы сделать шаг градиентного спуска, нужны производные потери по **каждому** из миллиардов параметров. Считать их по отдельности невозможно. Backpropagation считает их **все за один обратный проход**, стоимость которого примерно равна прямому. Это и есть причина, по которой глубокое обучение вообще работает.

## Граф вычислений

Любое вычисление модели — граф элементарных операций: умножения, сложения, функции активации. Каждая операция знает только свою **локальную производную**: для $m = w \cdot x$ это $\partial m / \partial w = x$, для $z = m + b$ — единица.

## Цепное правило

$$
\frac{\partial L}{\partial w} = \frac{\partial L}{\partial d}\cdot\frac{\partial d}{\partial z}\cdot\frac{\partial z}{\partial m}\cdot\frac{\partial m}{\partial w}
$$

Backprop идёт от потери назад и на каждом узле умножает пришедший градиент на локальную производную:

Два прохода:

1. **Вперёд**: от входов к потере, запоминая промежуточные значения (они понадобятся для локальных производных).
2. **Назад**: от $\partial L/\partial L = 1$ к параметрам. Если узел используется в нескольких местах, градиенты от всех путей **складываются**.

Это **обратный режим** автоматического дифференцирования. Он эффективен, потому что выход один (скалярная потеря), а входов — миллиарды.

## Что из этого следует на практике

- **Память**: для обратного прохода нужно хранить активации всех слоёв. На больших моделях именно активации, а не веса, съедают память при обучении. Решение — **gradient checkpointing**: хранить часть активаций и пересчитывать остальные (≈ +30% вычислений).
- **Затухание и взрыв градиентов**: градиент — произведение множителей по всем слоям. Если множители меньше 1 — затухает, больше — взрывается. Отсюда residual-связи (у градиента есть «прямая дорога» через $x + f(x)$), нормализация слоёв и аккуратная инициализация.
- **Активации**: у sigmoid производная не больше 0.25 — в глубокой сети градиент тает. ReLU, GELU и SwiGLU пропускают градиент без сжатия.

## В PyTorch

```python
x = torch.tensor(2.0)
w = torch.tensor(0.5, requires_grad=True)
b = torch.tensor(0.3, requires_grad=True)
L = (w * x + b - 3.0) ** 2   # прямой проход строит граф
L.backward()                 # обратный: заполняет w.grad и b.grad
print(w.grad, b.grad)        # tensor(-6.8) tensor(-3.4)
```

<Takeaways>
- Модель — **граф** элементарных операций с известными локальными производными.
- **Цепное правило**: идём от потери назад, умножая на локальные производные; по разветвлениям градиенты **складываются**.
- Один обратный проход даёт градиенты по **всем** параметрам — стоимость ≈ прямому.
- Цена — **память на активации** (gradient checkpointing).
- Затухание/взрыв градиентов → residual-связи, нормализация, ReLU/GELU.
</Takeaways>
