Обучение нейросети — это поиск минимума функции потерь в пространстве из миллиардов параметров. Аналитически его не найти, поэтому идут маленькими шагами **против градиента** — в направлении наискорейшего убывания. Всё остальное — как выбрать размер и направление шага.

## Базовый шаг

$$
\theta \leftarrow \theta - \eta\,\nabla L(\theta)
$$

$\eta$ — **learning rate**. Градиент показывает, куда функция растёт быстрее всего; шаг в обратную сторону уменьшает потерю — если шаг достаточно маленький.

**SGD**: градиент считается не по всем данным, а по случайному мини-батчу. Он шумный, но дешёвый, и шум даже помогает выбираться из плохих мест.

## Проблема вытянутых долин

Реальные функции потерь устроены как узкие вытянутые долины: по одним направлениям круто, по другим — полого. Один learning rate не подходит обоим:

Попробуй:

- **SGD** с маленьким lr — ползёт по пологой оси. Увеличь lr — начинает скакать по крутой, а выше $2/\lambda_{max}$ (здесь $2/12$) — **расходится**.
- **Momentum** накапливает скорость: колебания поперёк долины гасят друг друга, движение вдоль неё складывается.
- **Adam** масштабирует шаг для каждого параметра отдельно — на корень из скользящего среднего квадрата градиента.

## Оптимизаторы

| Оптимизатор | Идея |
|---|---|
| SGD | шаг против градиента мини-батча |
| Momentum / Nesterov | экспоненциальное среднее градиентов — инерция |
| RMSProp | делить на скользящий RMS градиента по каждому параметру |
| **Adam** | momentum + RMSProp + поправка смещения в начале |
| **AdamW** | Adam, где weight decay применяется отдельно от адаптивного шага — стандарт для трансформеров |

## Расписание learning rate

- **Warmup**: первые сотни-тысячи шагов lr растёт от нуля. В начале статистики Adam неточные, а градиенты огромные — без разогрева обучение трансформера легко взрывается.
- **Затухание** (cosine decay): ближе к концу шаг уменьшается, чтобы осесть в минимуме, а не прыгать вокруг.
- **Размер батча и lr** связаны: больший батч — менее шумный градиент, обычно позволяет больший lr.

## Когда что-то идёт не так

- Loss — **NaN или взлетает**: lr слишком большой, нет warmup, нужен gradient clipping (ограничить норму градиента).
- Loss **не падает**: lr слишком маленький, ошибка в данных или в разметке, мёртвые активации.
- **Train падает, validation растёт** — переобучение: регуляризация, больше данных, ранняя остановка.

<Takeaways>
- Шаг: $\theta \leftarrow \theta - \eta \nabla L$; SGD — по мини-батчу.
- Вытянутые долины: lr ограничен **самой крутой** осью, пологие оси ползут.
- **Momentum** гасит колебания, **Adam** масштабирует шаг по каждому параметру; для трансформеров — **AdamW**.
- **Warmup + cosine decay**, gradient clipping.
- NaN — lr/warmup; нет прогресса — lr/данные; разрыв train/val — переобучение.
</Takeaways>
