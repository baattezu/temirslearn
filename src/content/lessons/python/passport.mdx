Python — самый популярный язык в мире по большинству рейтингов, и при этом один из самых медленных. Это не противоречие, а ставка: **время программиста дороже времени процессора**. Поймёшь эту ставку — поймёшь, где Python король, а где его брать не надо.

## Откуда взялся

Рождество 1989 года, Амстердам. **Гвидо ван Россум** работает в исследовательском институте CWI и скучает на каникулах. Его раздражает выбор: писать служебные скрипты на C — долго и многословно, на shell — быстро, но всё, что сложнее пары строк, превращается в нечитаемую кашу. Он берёт идеи учебного языка ABC (читаемость, отступы) и делает язык «между C и shell». Название — в честь комик-группы «Монти Пайтон», а не змеи.

Первая версия вышла в 1991 году. Python 2 (2000) сделал язык массовым. Python 3 (2008) исправил старые ошибки — строки стали Unicode, `print` стал функцией — ценой **несовместимости**. Миграция заняла больше десяти лет: Python 2 официально похоронили только в 2020-м. Это главный урок истории Python, и поэтому Java так держится за совместимость.

## Философия: Zen of Python

Набери в интерпретаторе `import this` — и получишь манифест языка. Главные строки:

- *Beautiful is better than ugly.* Красивое лучше уродливого.
- *Explicit is better than implicit.* Явное лучше неявного.
- *Simple is better than complex.* Простое лучше сложного.
- *Readability counts.* Читаемость важна.
- *There should be one — and preferably only one — obvious way to do it.* Должен быть один очевидный способ (в отличие от Perl с девизом «есть больше одного способа»).

Отсюда **отступы как синтаксис**: код, который выглядит вложенным, и есть вложенный. Отсюда же «питоничный» код — идиомы, которые читаются как английский: `if x in seen`, `for i, x in enumerate(xs)`, `with open(f) as fh`.

## Ставки и цена

| Ставка | Что даёт | Чем платишь |
|---|---|---|
| динамическая типизация | меньше кода, быстрый прототип | ошибки типов в рантайме; лечится type hints + mypy |
| всё — объект | гибкость, метапрограммирование | каждое число — объект в куче со счётчиком ссылок |
| интерпретатор CPython | пишешь → сразу запускаешь | в 10–100 раз медленнее C на чистых циклах |
| «батарейки в комплекте» | стандартная библиотека на все случаи | огромная поверхность, разные стили |
| GIL | простая реализация, безопасные C-расширения | потоки не ускоряют CPU-задачи |

## Почему медленный язык правит ML

Потому что Python — **клей**. Тяжёлая работа никогда не выполняется в Python:

```python
import numpy as np
a = np.random.rand(10_000_000)
s = (a[a % 2 < 1] ** 2).sum()   # цикл идёт внутри numpy на C, а не в интерпретаторе
```

numpy, pandas, PyTorch написаны на C, C++ и CUDA. Python лишь описывает, **что** посчитать, — одним вызовом на миллион элементов. Цикл `for` по тем же десяти миллионам элементов на чистом Python был бы в десятки раз медленнее.

Отсюда правило: **векторизуй**, не пиши циклы по данным. И отсюда же вся экосистема ML: исследователь пишет на удобном языке, а инженеры NVIDIA и Meta оптимизируют ядра.

## Как исполняется

`.py` → компиляция в **байткод** (`.pyc` в `__pycache__`) → **виртуальная машина CPython** исполняет его инструкция за инструкцией. Посмотреть байткод можно модулем `dis`:

```python
import dis
dis.dis(lambda a, b: a + b)
#   LOAD_FAST   a
#   LOAD_FAST   b
#   BINARY_OP   + 
#   RETURN_VALUE
```

Та же стековая машина, что в JVM, но **без мощного JIT**: `BINARY_OP +` каждый раз выясняет типы операндов заново. В 3.11 добавили специализацию «на лету» (быстрее на 10–60%), в 3.13 — экспериментальный JIT и сборку без GIL. Альтернативы: **PyPy** (JIT, в разы быстрее на чистом Python), **Cython** и **Rust через PyO3** для горячих мест.

## Где Python живёт, а где его нет

| Живёт | Почему |
|---|---|
| ML, data science, аналитика | numpy/pandas/PyTorch, Jupyter — экосистема без альтернатив |
| автоматизация, скрипты, DevOps | быстро написать, есть везде |
| бэкенд API (Django, FastAPI) | скорость разработки, асинхронность в FastAPI |
| учёба, наука | читаемость, низкий порог входа |
| LLM-приложения и агенты | SDK провайдеров и библиотеки RAG сначала выходят на Python |

| Не живёт | Почему |
|---|---|
| мобильные приложения | нет нативной платформы |
| фронтенд | браузер понимает JS/WASM |
| системный код, драйверы, игровые движки | скорость и контроль памяти |
| высоконагруженные CPU-сервисы | GIL и интерпретатор; выносят горячее в Go, Rust, C++ |
| микроконтроллеры | только MicroPython для хобби и прототипов |

<Callout kind="tip" title="На собесе">

<Takeaways>
- Python (1991, Гвидо ван Россум) — язык «между C и shell»: ставка на **читаемость и время программиста**.
- **Zen of Python**: явное лучше неявного, читаемость важна, один очевидный способ. Отступы — синтаксис.
- Python 2 → 3 — болезненная несовместимая миграция длиной в десять лет.
- Медленный, потому что интерпретатор без мощного JIT, всё — объект, GIL. **Правит ML, потому что он клей** над C/C++/CUDA.
- Переменная — **имя, привязанное к объекту**; присваивание не копирует.
- Живёт в ML, автоматизации, API и LLM-приложениях; нет его в мобильной разработке, фронтенде и системном коде.
</Takeaways>
