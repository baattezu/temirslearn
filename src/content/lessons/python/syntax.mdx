Если ты уже прошёл синтаксис Java, этот урок короче: те же идеи, но питоничные. Главное — не писать на Python «как на Java» с геттерами, индексами и классами на каждый чих.

## Структура и отступы

Блок задаётся **отступом** (4 пробела), а не скобками. Двоеточие открывает блок.

```python
def greet(name: str, times: int = 1) -> str:   # аннотации типов — подсказки, не проверка
    """Докстринг: описание функции."""
    if not name:
        raise ValueError("пустое имя")
    return ", ".join(f"Привет, {name}" for _ in range(times))

if __name__ == "__main__":     # выполняется только при запуске файла, не при импорте
    print(greet("Ада", 2))
```

У функций есть значения по умолчанию и именованные аргументы: `greet(times=3, name="Алан")`. В Java это делают перегрузками и билдерами.

## Встроенные типы

```python
n = 10 ** 100          # int не переполняется — длинная арифметика
x = 7 / 2              # 3.5 — деление всегда float
y = 7 // 2             # 3 — целочисленное
s = "строка"           # неизменяемая, Unicode
t = (1, "a")           # кортеж — неизменяемый
xs = [3, 1, 2]         # список — изменяемый
d = {"ada": 36}        # dict — сохраняет порядок вставки (3.7+)
st = {1, 2, 3}         # set
nothing = None
```

Истинность: пустые `""`, `[]`, `{}`, `0` и `None` — ложные. Поэтому `if xs:` вместо `if len(xs) > 0:`.

## Срезы и распаковка

```python
xs[1:3]        # элементы 1 и 2
xs[-1]         # последний
xs[::-1]       # развернуть
a, b = b, a    # обмен без временной переменной
first, *rest = [1, 2, 3]       # first = 1, rest = [2, 3]
def f(*args, **kwargs): ...    # произвольные позиционные и именованные аргументы
```

## Словари — рабочая лошадь

```python
from collections import Counter, defaultdict

counts = Counter(words)                 # частоты за одну строку
counts.most_common(3)
by_city = defaultdict(list)
for u in users:
    by_city[u.city].append(u)           # не надо проверять «есть ли ключ»
age = d.get("alan", 0)                  # значение по умолчанию
```

## Классы и dataclass

<Compare

        return Math.sqrt(x * x + y * y);

  right={{ label: "Python dataclass", lang: "python", code: `from dataclasses import dataclass

  note={<><code>self</code> передаётся явно — «явное лучше неявного». Приватности нет: <code>_name</code> — договорённость «не трогай», <code>__name</code> — искажение имени, а не защита.</>}
/>

Геттеры и сеттеры не пишут: поле публичное, а если позже нужна логика — превращают его в `@property`, и вызывающий код не меняется.

## Исключения и ресурсы

```python
try:
    with open(path, encoding="utf-8") as f:    # with закроет файл, как try-with-resources
        data = f.read()
except FileNotFoundError:
    data = ""
except OSError as e:
    raise RuntimeError("не прочитать конфиг") from e   # цепочка причин
else:
    print("прочитали")     # выполнится, если исключения не было
finally:
    print("всегда")
```

Все исключения «unchecked» — объявлять ничего не нужно. Стиль Python — **EAFP** («проще попросить прощения»): сначала делаем, ловим ошибку, а не проверяем всё заранее.

## Функции как значения, генераторы

```python
sorted(users, key=lambda u: (u.city, -u.age))   # сортировка по составному ключу
max(orders, key=lambda o: o.total)

def read_lines(path):          # генератор: отдаёт по строке, не держит файл в памяти
    with open(path) as f:
        for line in f:
            yield line.rstrip()

total = sum(len(l) for l in read_lines("big.log"))
```

## Типы — по желанию, но в проде обязательно

```python
from typing import Literal

def charge(amount: int, currency: Literal["KZT", "USD"]) -> str | None: ...
```

Интерпретатор аннотации **не проверяет**. Проверяют `mypy` или `pyright` до запуска, а FastAPI и pydantic используют их для валидации входных данных. В серьёзном проекте аннотации и проверка в CI — норма.

<Takeaways>
- Блоки — **отступами**; функции с значениями по умолчанию и именованными аргументами.
- `int` без переполнения, `/` — всегда float, `//` — целочисленное; пустые коллекции ложны.
- Перебирай **элементы**, а не индексы: `enumerate`, `zip`, **list comprehension**, генераторы.
- `Counter`, `defaultdict`, `dict.get` — инструменты на каждый день.
- `@dataclass` вместо ручных классов; `self` явный; приватность — договорённость; `@property` вместо геттеров.
- Исключения не объявляются; стиль EAFP; `with` для ресурсов.
- Аннотации типов не проверяются рантаймом — проверяет mypy/pyright.
</Takeaways>
