Браузер начинался как программа для чтения документов, а стал операционной системой: в нём работают почта, офис, видеосвязь, IDE и игры. Chrome сегодня по сложности сравним с ядром Linux. Понять, почему он устроен именно так, проще всего через историю — она почти целиком состоит из войн.

## Что принёс Chrome

Chrome в 2008 году сделал две вещи, которые определили современный браузер.

**1. Многопроцессная архитектура.** Раньше браузер был одним процессом: упала одна вкладка — упали все, а уязвимость на одном сайте давала доступ ко всему. В Chrome каждая вкладка (теперь — каждый сайт) живёт в **отдельном процессе-песочнице** без доступа к файлам и сети. Общается с остальными через главный процесс. Цена — много памяти, отсюда шутки про Chrome и RAM.

**2. V8 и JIT для JavaScript.** До V8 JS интерпретировали, и он считался игрушечным языком. V8 компилирует горячий код в машинный, со скрытыми классами и inline-кэшами — те же идеи, что в JVM. JavaScript стал достаточно быстрым для Google Docs, Figma, VS Code и Node.js.

## Браузер как ОС

| ОС | Браузер |
|---|---|
| процессы и изоляция | процесс на сайт, песочница, Site Isolation |
| планировщик | event loop главного потока, задачи и микрозадачи |
| графика | конвейер рендеринга: стиль → layout → paint → composite на GPU |
| файловая система, БД | IndexedDB, Cache Storage, OPFS |
| системные вызовы | Web API: fetch, WebSocket, WebRTC, WebGPU |
| исполняемые файлы | JavaScript и WebAssembly |

Отсюда главная мысль трека: **главный поток — один**. Он и исполняет твой JS, и считает layout, и отвечает на клики. Заняла его тяжёлая функция на 300 мс — страница «замёрзла». Почти все проблемы фронтенд-производительности — про то, чем занят главный поток.

## Карта трека

1. **Рендеринг** — от HTML до пикселей: что такое reflow и почему `transform` дешевле `top`.
2. **Event loop** — задачи, микрозадачи и кадры.
3. **V8** — JIT, скрытые классы и почему форма объектов важна.

<Takeaways>
- Браузер прошёл путь от просмотрщика документов (1990) до **операционной системы для приложений**.
- Войны браузеров: Netscape против IE, потом Firefox и Chrome. Сегодня почти все на движке **Blink**, независимы WebKit и Gecko.
- Chrome (2008): **процесс на сайт** (изоляция) и **V8 с JIT** — JavaScript стал быстрым, появился Node.js.
- Главный поток один: JS, layout и обработка событий делят его. Отсюда почти все проблемы производительности фронтенда.
</Takeaways>
