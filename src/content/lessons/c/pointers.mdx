Указатель — это просто число: адрес байта в памяти, плюс тип, который говорит компилятору, что там лежит и сколько оно занимает. Всё остальное в C — массивы, строки, структуры данных, передача «по ссылке» — построено на этом.

## Адрес и разыменование

```c
int x = 42;
int *p = &x;    // p хранит адрес x
*p = 7;         // пишем по адресу — x теперь 7
int **pp = &p;  // указатель на указатель
```

- `&x` — адрес переменной, `*p` — значение по адресу.
- Указатель занимает 8 байт на 64-битной платформе, на что бы он ни указывал.
- `NULL` — «никуда»; разыменовать его — undefined behaviour (на практике — segfault).

## Адресная арифметика

`p + 1` прибавляет не один байт, а `sizeof(*p)` байт — сдвиг на следующий **элемент**. Поэтому `a[i]` — это по определению `*(a + i)`:

## Массивы «распадаются» в указатели

Почти в любом выражении имя массива превращается в указатель на первый элемент. Следствия, на которых ловятся все:

```c
void f(int a[10]) {          // на самом деле int *a
    printf("%zu", sizeof(a)); // 8 — размер указателя, не массива
}
int arr[10];
printf("%zu", sizeof(arr));  // 40 — здесь arr ещё массив
f(arr);                      // передаётся адрес, размер теряется
```

Поэтому в C функции принимают пару `(указатель, длина)`, а строки заканчиваются нулевым байтом `'\0'` — иначе длину не узнать. `strlen` — это O(n) поиск нуля, а забытый `'\0'` — чтение за пределами буфера.

## const и указатели

Читается справа налево:

| Объявление | Можно менять указатель | Можно менять данные |
|---|---|---|
| `const int *p` | да | нет |
| `int *const p` | нет | да |
| `const int *const p` | нет | нет |

## Указатели на функции и void*

- `void *` — «адрес чего-то»: так устроены `malloc`, `memcpy`, `qsort`. Перед разыменованием приводят к нужному типу.
- Указатель на функцию: `int (*cmp)(const void*, const void*)` — так `qsort` принимает компаратор. На этом строят колбэки и таблицы виртуальных функций.

<Callout kind="warn" title="Strict aliasing">
Нельзя читать объект через указатель несовместимого типа: `*(float*)&some_int` — UB. Компилятор вправе считать, что `int*` и `float*` никогда не указывают на одно и то же, и переставлять чтения. Для перетолковывания байтов используй `memcpy` — оптимизатор превратит его в одну инструкцию.
</Callout>

<Takeaways>
- Указатель — адрес + тип; `&` — взять адрес, `*` — разыменовать.
- `p + i` сдвигает на `i * sizeof(*p)` байт; `a[i]` ≡ `*(a + i)`.
- Массив в выражениях и параметрах **распадается** в указатель: `sizeof` в функции — 8.
- Поэтому передают `(ptr, len)`, а строки завершаются `'\0'`.
- `const` читается справа налево; `void*` — обобщённый адрес; strict aliasing — читать через `memcpy`.
</Takeaways>
