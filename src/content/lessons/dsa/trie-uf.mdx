Две специализированные структуры, которые часто дают «вау»-решение на собесе: **trie** для задач со строками и префиксами и **Union-Find** для задач о связности. Обе пишутся за 15 строк.

## Trie (префиксное дерево)

Каждый узел — символ, путь от корня — префикс. Слова с общим началом делят общий путь. Узлы, где заканчивается слово, помечены.

<TrieViz />

- `insert(word)` и `search(word)` — O(длины слова), независимо от числа слов.
- `startsWith(prefix)` — спуститься по префиксу, а всё поддерево — его продолжения. Автодополнение, проверка орфографии, маршрутизация по IP (самый длинный совпадающий префикс).
- Задачи: Implement Trie, Word Search II (trie из словаря + DFS по доске — отсекаем путь, как только префикса нет в trie), Replace Words, Longest Common Prefix.

```python
class Trie:
    def __init__(self):
        self.root = {}
    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node["$"] = True                  # конец слова
    def starts_with(self, prefix):
        node = self.root
        for ch in prefix:
            if ch not in node:
                return False
            node = node[ch]
        return True
```

Цена — память: на каждый символ узел со словарём детей. Для больших словарей используют сжатые варианты (radix tree, DAWG).

## Union-Find (система непересекающихся множеств)

Отвечает на два вопроса почти за O(1): **«в одном ли множестве a и b?»** и **«объединить множества a и b»**. Каждое множество — дерево, представитель — его корень.

<UnionFind />

Две оптимизации делают операции почти константными (обратная функция Аккермана — меньше 5 для любых реальных n):

- **объединение по рангу**: меньшее дерево подвешивается под большее — деревья остаются низкими;
- **сжатие путей**: во время `find` все пройденные узлы перевешиваются прямо на корень.

```python
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]     # сжатие пути (половинное)
        x = parent[x]
    return x
def union(a, b):
    ra, rb = find(a), find(b)
    if ra == rb:
        return False                      # уже связаны — это ребро образует цикл
    parent[rb] = ra
    return True
```

Задачи: Number of Provinces, Redundant Connection (первое ребро, у которого концы уже в одном множестве), Accounts Merge, **алгоритм Краскала** для минимального остовного дерева, Number of Islands II (острова добавляются по одному — BFS каждый раз был бы дорог).

<Takeaways>
- **Trie**: путь = префикс; insert/search/startsWith за O(длины); автодополнение, Word Search II.
- **Union-Find**: `find` (корень) и `union`; связность и циклы почти за O(1).
- Ранг + **сжатие путей** — обе оптимизации вместе дают α(n) ≈ константу.
- Union-Find — основа Краскала и онлайн-подсчёта компонент.
</Takeaways>
