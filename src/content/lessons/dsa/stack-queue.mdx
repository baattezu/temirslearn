Стек и очередь — самые простые структуры, но на них держится огромный класс задач: скобки, вычисление выражений, «следующий больший элемент», BFS, скользящий максимум, undo. Главное — узнавать, **какой порядок обработки** нужен задаче.

## Стек и очередь

- **Стек** (LIFO): последний пришёл — первый ушёл. `push`, `pop`, `peek` — O(1). Это порядок вложенности: скобки, вызовы функций, DFS, отмена действий.
- **Очередь** (FIFO): первый пришёл — первый ушёл. Порядок прихода: BFS, буферы, планирование.
- **Дек** (deque): добавлять и забирать с обоих концов. Обобщает оба.

В Java для всего этого — `ArrayDeque` (не `Stack` — он синхронизирован и наследует `Vector`, и не `LinkedList` — лишние объекты на каждый элемент). В Python — `list` для стека и `collections.deque` для очереди (`list.pop(0)` — O(n)!).

## Кольцевой буфер

`ArrayDeque` устроен как **кольцевой буфер**: массив и два индекса — `head` и `tail`, которые идут по кругу (`(i + 1) & (capacity − 1)`). Добавление и удаление с обоих концов — O(1) без сдвига элементов. Когда буфер полон, ёмкость удваивается, как у динамического массива. Тот же приём используют очереди в ядре ОС, сетевых картах и LMAX Disruptor.

## Скобки

```python
def valid(s: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    st = []
    for ch in s:
        if ch in "([{":
            st.append(ch)
        elif not st or st.pop() != pairs[ch]:
            return False
    return not st
```

Каждая закрывающая скобка должна совпасть с **последней** незакрытой — это ровно LIFO. В «Задачах» — Valid Parentheses.

## Монотонный стек

Задачи вида «для каждого элемента найти **ближайший справа больший** / меньший» наивно решаются за O(n²). Монотонный стек делает это за O(n): в стеке лежат индексы, для которых ответ ещё не найден, и значения в нём убывают. Пришёл элемент больше вершины — он и есть ответ для всех меньших на вершине:

Каждый индекс один раз кладётся и один раз снимается — O(n). На этом шаблоне: Daily Temperatures, Next Greater Element, Largest Rectangle in Histogram, Trapping Rain Water, Stock Span.

## Монотонная очередь: максимум в окне

Скользящий максимум окна длины k за O(n): в деке храним индексы с **убывающими** значениями. Новый элемент выталкивает с хвоста всех, кто меньше (они уже никогда не станут максимумом), а голова выходит, когда покидает окно. Максимум всегда в голове.

<Callout kind="tip" title="Очередь на двух стеках">
Классический вопрос: сделать очередь из двух стеков. `push` — в стек `in`; `pop` — из стека `out`, а если он пуст, переложить в него всё из `in` (порядок развернётся). Каждый элемент перекладывается один раз — амортизированно O(1).
</Callout>

<Takeaways>
- **Стек** — вложенность (LIFO), **очередь** — порядок прихода (FIFO), **дек** — оба конца.
- В Java — `ArrayDeque` (кольцевой буфер), в Python — `list` и `deque`.
- Скобки, выражения, DFS, undo — стек; BFS, буферы — очередь.
- **Монотонный стек** — «ближайший больший/меньший» за O(n); **монотонный дек** — максимум в окне за O(n).
- Очередь на двух стеках — амортизированно O(1).
</Takeaways>
