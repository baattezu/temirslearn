Перебор с возвратом (backtracking) — систематический способ перебрать все варианты, строя решение по шагам и **отказываясь от ветки, как только видно, что она не приведёт к ответу**. Подмножества, перестановки, комбинации, судоку, расстановки — один шаблон.

## Шаблон

```python
def backtrack(state, choices):
    if is_solution(state):
        result.append(state.copy())
        return
    for choice in choices(state):
        if not valid(state, choice):      # отсечение — главное ускорение
            continue
        state.append(choice)              # сделать выбор
        backtrack(state, choices)
        state.pop()                       # отменить выбор
```

Три части: **выбор**, **проверка** (можно ли идти дальше), **отмена** выбора после возврата. Отмена — ключевой момент: состояние общее, и после рекурсии его надо вернуть как было.

## Ферзи

Без отсечений вариантов $n^n$; с проверкой на каждом шаге отбрасываются целые поддеревья, и для 8×8 решение находится за ~900 проверок.

## Три классические формы

| Задача | Дерево выбора | Сколько решений |
|---|---|---|
| **Подмножества** | для каждого элемента — взять или нет | $2^n$ |
| **Перестановки** | на каждой позиции — любой неиспользованный | $n!$ |
| **Комбинации из k** | следующий элемент — только правее предыдущего (чтобы не было повторов) | $\binom{n}{k}$ |

```python
def subsets(nums):
    res, cur = [], []
    def go(i):
        if i == len(nums):
            res.append(cur[:]); return
        go(i + 1)                 # не берём nums[i]
        cur.append(nums[i])
        go(i + 1)                 # берём
        cur.pop()
    go(0)
    return res
```

## Отсечения и дубликаты

- **Ранняя проверка**: проверяй ограничения при каждом выборе, а не в конце (как с ферзями — диагонали и столбцы).
- **Границы**: Combination Sum — если отсортировать кандидатов, то при сумме больше цели можно оборвать цикл целиком.
- **Дубликаты** во входе (Subsets II, Permutations II): сортируем и пропускаем элемент, равный предыдущему на том же уровне: `if i > start and nums[i] == nums[i-1]: continue`.
- **Мемоизация**: если подзадачи повторяются (одинаковое состояние разными путями) — это уже DP.

<Callout kind="tip" title="Как оценить сложность">
Число листьев дерева × работа на лист. Подмножества — $O(2^n \cdot n)$ (копирование), перестановки — $O(n! \cdot n)$. Если $n \le 20$ для подмножеств или $n \le 10$ для перестановок — перебор пройдёт. Больше — ищи DP, жадность или математику.
</Callout>

<Takeaways>
- Backtracking: **выбор → рекурсия → отмена выбора**; решение строится по шагам.
- **Отсечения** — главный источник скорости: проверяй ограничения как можно раньше.
- Формы: подмножества ($2^n$), перестановки ($n!$), комбинации ($\binom{n}{k}$).
- Дубликаты — сортировка + пропуск равного соседа на одном уровне.
- Повторяющиеся состояния → мемоизация → DP.
</Takeaways>
