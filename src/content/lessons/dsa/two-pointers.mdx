Два указателя и скользящее окно — способ убрать вложенный цикл. Вместо того чтобы перебирать все пары `(i, j)` за O(n²), двигаешь два индекса так, что каждый проходит массив **один раз** — O(n).

## Когда это работает

Ключ — **монотонность**: сдвиг указателя в одну сторону никогда не надо отменять. Три формы:

1. **Навстречу друг другу** — по отсортированному массиву. Two Sum II: если сумма мала, двигаем левый вправо, если велика — правый влево. Каждый шаг отбрасывает целую строку или столбец из таблицы пар.
2. **Быстрый и медленный** — в одну сторону с разной скоростью. Удаление дубликатов на месте, поиск цикла в списке (Флойд), середина списка.
3. **Скользящее окно** `[l, r)` — правый край расширяет, левый сужает, пока окно не станет «правильным». Подстроки и подмассивы с условием.

## Окно на примере

Самая длинная подстрока без повторяющихся символов. Наивно — проверить все O(n²) подстрок. Окном: правый край идёт по одному символу, а если символ уже в окне, **левый край прыгает** за его прошлое вхождение. Каждый индекс входит в окно и выходит из него один раз:

<SlidingWindow />

```python
def longest_unique(s: str) -> int:
    last = {}            # символ → последний индекс
    l = best = 0
    for r, ch in enumerate(s):
        if last.get(ch, -1) >= l:   # повтор внутри окна
            l = last[ch] + 1
        last[ch] = r
        best = max(best, r - l + 1)
    return best
```

## Шаблон окна переменной длины

```python
l = 0
for r in range(n):
    add(a[r])                  # расширяем вправо
    while not valid():         # сужаем, пока окно не станет допустимым
        remove(a[l]); l += 1
    answer = max(answer, r - l + 1)   # или min — для «кратчайшего»
```

Условие для шаблона: если окно `[l, r]` недопустимо, то и любое более широкое `[l', r]` с `l' < l` тоже. Тогда левый край можно не возвращать назад.

<Callout kind="warn" title="Где окно не работает">
Если в массиве есть **отрицательные** числа, задача «подмассив с суммой ≥ k» ломает монотонность: расширение окна может уменьшить сумму. Тогда нужны префиксные суммы + хеш-таблица или монотонная очередь.
</Callout>

## Задачи на паттерн

| Задача | Форма |
|---|---|
| Two Sum II, 3Sum | навстречу (3Sum: фиксируем один, двое навстречу) |
| Container With Most Water | навстречу: двигаем меньшую стенку |
| Remove Duplicates, Move Zeroes | медленный пишет, быстрый читает |
| Linked List Cycle | быстрый × 2, медленный × 1 |
| Longest Substring Without Repeating | окно + последний индекс |
| Minimum Window Substring | окно + счётчики, сужаем пока покрывает |
| Max Sum Subarray of size k | окно фиксированной длины |

Во вкладке **Задачи** — «Longest Substring Without Repeating Characters».

<Takeaways>
- Два указателя убирают вложенный цикл, если сдвиг **монотонен** — его не нужно откатывать.
- Формы: **навстречу** (отсортированный массив), **быстрый-медленный**, **скользящее окно**.
- Окно: расширяй вправо, сужай слева, пока условие не выполнится; оба края идут только вперёд → O(n).
- Отрицательные числа ломают окно по сумме — тогда префиксные суммы.
</Takeaways>
