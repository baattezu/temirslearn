Граф — это вершины и рёбра. Сетка из клеток, зависимости пакетов, друзья в соцсети, переходы между состояниями — всё графы. Две базовые процедуры обхода, BFS и DFS, решают огромную часть задач, и разница между ними — **одна строчка**: очередь или стек.

## Представление

- **Список смежности** `adj[v] = [соседи]` — стандарт. Память O(V + E).
- **Матрица смежности** — O(V²), годится для плотных графов и проверки ребра за O(1).
- **Сетка** — граф неявный: соседи клетки `(r, c)` — четыре направления, рёбра не хранятся.

## BFS и DFS

```python
from collections import deque
def bfs(start):
    seen = {start}
    q = deque([start])
    while q:
        v = q.popleft()          # ← очередь: FIFO
        for u in neighbors(v):
            if u not in seen:
                seen.add(u)      # отмечаем при добавлении, а не при извлечении
                q.append(u)
```

Замени `popleft()` на `pop()` — получится DFS-порядок на стеке. Посмотри, как по-разному они расходятся:

- **BFS** расходится **волной**: сначала все клетки на расстоянии 1, потом 2… Поэтому первый раз, когда BFS достаёт цель, путь до неё **кратчайший по числу рёбер**.
- **DFS** ныряет до упора в одном направлении. Путь находит, но не кратчайший. Зато он естественен для задач «обойти всё»: компоненты связности, топологическая сортировка, поиск циклов, перебор с возвратом.
- **Дейкстра** — BFS, где очередь заменена на **min-кучу по расстоянию**. Нужна, когда у рёбер разные веса. Включи «болото» и сравни путь BFS и Дейкстры.

## Сложность

Каждая вершина добавляется один раз, каждое ребро просматривается один-два раза: **O(V + E)**. Для сетки R × C — O(R·C). Дейкстра на куче — O((V + E) log V).

## Шаблоны задач

| Задача | Как |
|---|---|
| Number of Islands | для каждой непосещённой «земли» — BFS/DFS, счётчик +1 |
| Кратчайший путь в лабиринте | BFS от старта, `dist` при добавлении в очередь |
| Rotting Oranges, «огонь распространяется» | **многоисточниковый** BFS: все стартовые клетки в очередь сразу |
| Course Schedule | топологическая сортировка (Кан: очередь вершин с нулевой входящей степенью) |
| Есть ли цикл в ориентированном графе | DFS с тремя цветами: белый, серый (в стеке), чёрный |
| Word Ladder | BFS по неявному графу слов |
| Пути с весами 0/1 | 0-1 BFS на деке |

Во вкладке **Задачи** — Number of Islands.

<Callout kind="warn" title="Частые баги">
Отмечай вершину посещённой **при добавлении** в очередь, а не при извлечении — иначе одна клетка попадёт в очередь много раз, и BFS станет экспоненциально медленнее на плотных сетках. Рекурсивный DFS на сетке 1000 × 1000 переполнит стек — используй явный стек.
</Callout>

<Takeaways>
- Граф = список смежности; сетка — неявный граф с 4 соседями.
- **BFS** — очередь, волна, **кратчайший путь** в невзвешенном графе.
- **DFS** — стек или рекурсия, «обойти всё»: компоненты, циклы, топосортировка, backtracking.
- **Дейкстра** = BFS с min-кучей по расстоянию, для неотрицательных весов.
- Обе обходят за **O(V + E)**; отмечай вершину при добавлении.
</Takeaways>
