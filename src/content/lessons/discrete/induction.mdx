Индукция и рекурсия — одна идея с двух сторон. Рекурсия **решает** задачу через меньшую такую же; индукция **доказывает**, что это решение работает для всех размеров. Если понимаешь индукцию, перестаёшь бояться рекурсии: достаточно поверить, что рекурсивный вызов работает, и проверить один шаг.

## Принцип индукции

Чтобы доказать $P(n)$ для всех $n \ge n_0$:

1. **База**: $P(n_0)$ верно.
2. **Шаг**: из $P(n)$ следует $P(n + 1)$.

Это как домино: первое падает, и каждое роняет следующее.

**Пример**: $1 + 2 + \dots + n = \frac{n(n+1)}{2}$.

- База: $n = 1$: $1 = \frac{1 \cdot 2}{2}$.
- Шаг: пусть верно для $n$. Тогда $1 + \dots + n + (n+1) = \frac{n(n+1)}{2} + (n + 1) = \frac{(n+1)(n+2)}{2}$ — формула для $n + 1$.

**Сильная индукция**: в шаге можно опираться на $P(k)$ для **всех** $k \le n$, а не только на $P(n)$. Так доказывают, что любое число > 1 раскладывается на простые множители, и так работают рекурсии, делящие задачу не на $n - 1$, а пополам.

## Рекурсия = индукция в коде

Корректная рекурсивная функция устроена ровно как доказательство:

- **база рекурсии** = база индукции (`if n == 0: return …`);
- **рекурсивный шаг** = шаг индукции: предполагаем, что вызов на меньшем входе возвращает правильный ответ, и собираем из него ответ для текущего;
- **уменьшение размера** гарантирует, что рекурсия дойдёт до базы.

## Рекуррентные соотношения

Сложность рекурсии описывается рекуррентностью:

| Рекуррентность | Решение | Пример |
|---|---|---|
| $T(n) = T(n-1) + O(1)$ | $O(n)$ | обход списка |
| $T(n) = T(n/2) + O(1)$ | $O(\log n)$ | бинарный поиск |
| $T(n) = 2T(n/2) + O(n)$ | $O(n \log n)$ | сортировка слиянием |
| $T(n) = 2T(n-1) + O(1)$ | $O(2^n)$ | Ханой, наивный Фибоначчи |

Для «разделяй и властвуй» есть **основная теорема** (master theorem): для $T(n) = aT(n/b) + O(n^d)$ ответ определяется сравнением $d$ с $\log_b a$.

<Callout kind="warn" title="Ловушка «доказательства» индукцией">
«Все лошади одного цвета»: база — одна лошадь; шаг — из n + 1 лошадей убираем первую (остальные n одного цвета), потом последнюю (снова n одного цвета), значит все одного цвета. Ошибка — шаг не работает при переходе от 1 к 2: два подмножества не пересекаются. Шаг должен быть верен **для каждого** n, начиная с базы.
</Callout>

<Takeaways>
- Индукция: **база** + **шаг** $P(n) \Rightarrow P(n+1)$; сильная — опора на все меньшие.
- Рекурсия — та же схема: база, вызов на меньшем, доверие к рекурсивному вызову.
- Сложность рекурсии — **рекуррентное соотношение**: $T(n/2)$ даёт log, $2T(n/2) + n$ — n log n, $2T(n-1)$ — $2^n$.
- Шаг индукции должен работать для **каждого** n от базы.
</Takeaways>
